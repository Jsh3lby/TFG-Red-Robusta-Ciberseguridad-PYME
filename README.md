# TFG-Red-Robusta-Ciberseguridad-PYME

Proyecto Intermodular - Administración de Sistemas Informáticos en Red (ASIR)

Curso académico: 2026-2027
Autor: Jorge Herrera Pascual
Empresa de simulación: Ventix
Sector: Marketing
Plantilla: 35 empleados

1. Descripción del proyecto

Este proyecto tiene como finalidad diseñar e implementar una infraestructura de ciberseguridad defensiva, segura y de bajo coste, dirigida a pequeñas y medianas empresas (PYMES).

La solución pretende mejorar la protección de redes, sistemas y datos mediante la segmentación de red, la gestión centralizada de usuarios y permisos, el control de accesos y la monitorización de eventos de seguridad.

Para desarrollar y validar la propuesta se utilizará como escenario práctico Ventix, una empresa ficticia dedicada al marketing, con 35 empleados distribuidos en cuatro departamentos:

Administración y Finanzas.

Desarrollo.

Comunicación.

Publicidad.

La infraestructura se reproducirá mediante un laboratorio virtual, utilizando herramientas gratuitas y de código abierto.

2. Objetivos

Diseñar una arquitectura de red segura y segmentada.

Implementar servicios de administración centralizada y protección de la infraestructura.

Configurar un sistema de monitorización y realizar pruebas controladas de seguridad.

4. Estructura del proyecto

La documentación, configuraciones y evidencias se organizarán en diferentes directorios:

01-Anteproyecto: documentación inicial del proyecto.

02-Documentacion: diseño y documentación técnica.

03-Diagramas: diagramas de red y arquitectura.

04-Configuraciones: configuraciones de los servicios implantados.

05-Pruebas: procedimientos y resultados de las pruebas.

06-Evidencias: capturas y evidencias del funcionamiento.

5. Entorno de laboratorio

El proyecto se desarrollará en un entorno virtual utilizando Oracle VirtualBox sobre Windows 11.

Debido a las limitaciones de recursos del equipo, se establece un máximo de dos máquinas virtuales encendidas simultáneamente. Las pruebas se organizarán por escenarios para validar los distintos componentes de la infraestructura sin superar esta limitación.

6. Alcance

El proyecto contempla el diseño de una arquitectura adaptable a diferentes PYMES y su validación práctica mediante simulaciones basadas en la empresa ficticia Ventix.

La implementación se centrará en las funcionalidades principales de segmentación de red, gestión centralizada de usuarios y monitorización de seguridad. Las funcionalidades adicionales se abordarán en función del tiempo y los recursos disponibles.
